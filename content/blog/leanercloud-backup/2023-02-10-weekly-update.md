## LeanerCloud GUI

Development of the new GUI has made substantial progress. The interface can now estimate savings and update projections based on selected Auto Scaling Groups (ASGs) and their configurations. Tag reading and writing functionality for commonly-used parameters is operational, with previous run values retrievable.

Some cosmetic refinements remain, but core tagging functionality works reliably. The author plans to demonstrate this to prospects during sales calls and use it for larger AutoSpotting deployments. A Loom video showcasing the current state was recorded, though a bug in AutoSpotting was discovered during filming.

Future improvements include EBS Optimizer support and expanded AutoSpotting configuration options, potentially including Reserved Instance considerations and multi-region ASG visibility.

## Outreach to AutoSpotting OSS Users

The author resumed efforts to connect with AutoSpotting users by targeting those who forked the repository. Initial manual outreach proved time-consuming, reaching only a small percentage daily.

Automation was implemented with ChatGPT assistance to collect fork authors' contact information for feedback solicitation. The goal involves gathering testimonials and identifying improvement opportunities. Plans include extending this approach to GitHub issue reporters and repository watchers, plus similar campaigns for the Terraform AutoSpotting repository.

## Talking to People

Stakeholder conversations yielded insights for product development and marketing strategy refinement. Discussed improvements include:

- Automatic instance type information updates or attribute-based selection
- Reserved Instance and Savings Plan integration
- Multi-type failover capabilities for instance replacement
- Mixed Instances ASG support

The author encourages audience input on desired features.
