Cristian has decided to release all his CLI tools and Terraform building blocks under the 37signals ONCE Model, using their source-available license.

## What's Included

### Optimizer Tool

The initial release features Optimizer, a flagship CLI application for automating AWS resource optimization. This tool targets hands-on FinOps consultants and organizations undertaking large-scale optimization projects.

**Main capabilities:**

- Mass conversion to GP3 for EC2 EBS volumes and RDS storage, with options to maintain original IOPS/throughput settings
- Rightsizing with Graviton conversion support for RDS, ElastiCache, and OpenSearch based on CloudWatch metrics
- Resource selection using tags in opt-in and opt-out modes to control scope
- Plan/apply modes similar to Terraform workflows

## Coming Soon

Over the following weeks, the author plans to gradually release a dozen additional AWS cost optimization tools and Terraform building blocks previously used in customer engagements.

## How It Works

After purchase, customers provide their GitHub username and receive access to the LeanerCloud-ONCE organization containing full source code and future updates. Limited support is available through the LeanerCloud Slack community.

## Pricing & Access

- **Stripe:** $499 one-time payment
- **AWS Marketplace:** $699 (includes higher payment processing fees)

Pricing increases as new tools are added. The author notes this introductory price is temporary.

## Updates

The bundle later expanded to include Terraform building blocks with pricing adjusted to $799. Discussions are available on HackerNews and Reddit.
