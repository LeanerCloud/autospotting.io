The inaugural 2023 update from LeanerCloud News marks the transition to Beehiiv, continuing Cristian's weekly reflections on building and entrepreneurship.

## Slow Start to the Year

Cristian took extended time off during the holidays with family and guests. Work resumed Thursday after his son returned to kindergarten. He spent the day networking via Slack and LinkedIn, improving his Notion CRM, and scheduling calls with friends, customers, and prospects.

## AWS Marketplace Reporting Tool

Inspired by frustration with AWS Marketplace's lack of seller dashboards, Cristian began developing an automation script. The platform only provides raw CSV files in S3 without aggregation or customer identification features.

Using ChatGPT's assistance, he created a Go script to download and parse CSV data into structured formats. He noted that ChatGPT excels with statically-typed languages like Go, efficiently handling boilerplate code for AWS authentication and S3 downloads—"like Github Copilot on steroids."

The project remains incomplete but functional. Once polished for personal use, he considers monetizing it on the Marketplace.

## EBS Optimizer Development

Cristian prepared for a new AWS Marketplace release by testing, refining the build system, and simplifying product descriptions. He plans to complete this work soon, then focus on developing a GUI that estimates savings before running the tools—feedback he's consistently received.
